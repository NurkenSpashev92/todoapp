# 0002. Интерфейсы в `contract.go` на стороне реализации

- Статус: Accepted
- Дата: 2026-11-02

## Контекст

Изначально интерфейсы объявлялись у потребителя (`UserRepositoryInterface` в `service.go`, `UserSerivce` в `transport.go`) — идиоматичный для Go подход. На практике это давало дублирование сигнатур и затрудняло поиск контракта слоя.

## Решение

- Интерфейс слоя лежит в файле `contract.go` в пакете этого слоя:
  - `features/<x>/repository/contract.go` → `<X>RepositoryInterface`;
  - `features/<x>/service/contract.go` → `<X>ServiceInterface`.
- Потребитель импортирует интерфейс из пакета слоя ниже.
- Реализация содержит compile-time проверку `var _ <Iface> = (*<Impl>)(nil)`.

## Последствия

- Контракт каждого слоя виден в одном файле.
- Отход от Go-идиомы «accept interfaces, defined by consumer» — принят сознательно ради единообразия.
- Моки для тестов генерируются/пишутся по одному интерфейсу на слой.
