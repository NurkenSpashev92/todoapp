# 0009. Статистика вычисляется при чтении

- Статус: Accepted
- Дата: 2026-11-02

## Контекст

Нужны метрики: создано/выполнено задач, процент выполнения, среднее время выполнения — с фильтром по пользователю и периоду.

## Решение

- Таблицы `statistics` нет. `GET /statistics` выполняет один агрегирующий SQL по `todoapp.tasks`
  (`COUNT`, `COUNT FILTER`, `AVG(completed_at - created_at)`).
- Фильтры опциональны: `user_id`, `from`, `to` (`[from, to)` по `created_at`).
- Процент считается при конвертации Model → domain; `nil`, если задач нет.
- Индекс `idx_tasks_author_user_id_created_at` (миграция 000002).

## Последствия

- Данные всегда актуальны, нет синхронизации.
- На очень больших объёмах может понадобиться материализованное представление — отдельный ADR.
