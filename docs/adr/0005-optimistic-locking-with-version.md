# 0005. Оптимистичная блокировка через `version`

- Статус: Accepted
- Дата: 2026-11-02

## Контекст

PATCH читает сущность, применяет изменения в domain и сохраняет. Между чтением и записью сущность может измениться.

## Решение

- Каждая таблица имеет `version BIGINT NOT NULL DEFAULT 1`.
- `UPDATE ... SET ..., version=version+1 WHERE id=$n AND version=$m RETURNING ...`.
- Нет строки → сущность изменена конкурентно → ошибка.

## Последствия

- Без блокировок строк и транзакций на чтение.
- Клиент получает актуальную `version` в каждом ответе.
- Для `tasks` конфликт возвращается как `ErrConflict` (409); `users` пока возвращает `ErrNotFound` — см. known-issues.
