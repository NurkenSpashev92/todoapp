# 0004. Сырой SQL через pgx, без ORM

- Статус: Accepted
- Дата: 2026-11-02

## Контекст

Запросы простые, нужна полная видимость SQL и контроль производительности.

## Решение

- Драйвер `jackc/pgx/v5` с `pgxpool`; репозитории зависят от интерфейса `core_postgres_pool.Pool`.
- SQL — raw-строки в методах репозитория, схема `todoapp.` явно, плейсхолдеры `$n`.
- Результат сканируется в `<X>Model`, затем конвертируется в domain.
- Таймаут каждой операции — `pool.OpTimeout()` (`POSTGRES_TIMEOUT`).
- Схема — миграции `golang-migrate`.

## Последствия

- Нет магии и N+1 от ORM; агрегации (статистика) пишутся напрямую в SQL.
- Больше шаблонного кода (Scan, маппинг) — принято.
- Изменения схемы требуют синхронной правки SQL в репозиториях.
