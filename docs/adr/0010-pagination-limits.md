# 0010. Обязательная пагинация с лимитами

- Статус: Accepted
- Дата: 2026-11-02

## Контекст

Без `limit` запрос `LIMIT NULL` возвращал всю таблицу.

## Решение

- `domain.DefaultLimit = 20`, `domain.MaxLimit = 100`.
- Service: `limit == nil` → default; `limit > MaxLimit`, `limit < 0`, `offset < 0` → `ErrInvlidArgument` (400).
- Репозиторий предвыделяет срез по `limit` и всегда закрывает `rows`.

## Последствия

- Ограничено потребление памяти и соединений на один запрос.
- Изменение API: без `limit` возвращается не более 20 записей.
